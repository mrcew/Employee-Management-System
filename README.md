\# Employee Management System



\## Project Overview

A MySQL-based Employee Management System project designed to practise SQL queries and manage employee-related information.



\## Database

\- Database name: `employee\_management`

\- DBMS: MySQL



\## Tables

1\. employees

2\. departments

3\. attendance

4\. leaves

5\. salary\_history

6\. employee\_details



\## SQL Concepts

\- Database selection and table inspection

\- SELECT queries

\- Retrieving employee and department records

\## How to Run

1\. Open MySQL Command Line Client.

2\. Select the `employee\_management` database.

3\. Execute the SQL script using the SOURCE command.
